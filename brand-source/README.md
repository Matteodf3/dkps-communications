# DKPS logo source files

The original `Vector.ai`, `Vector.eps`, and `Vector.pdf` files supplied by DKPS are kept here for print and future vector production. The PDF contains light and dark layouts with a coloured symbol; its composition differs from the supplied monochrome JPEG references.

The website uses `public/brand/dkps-logo-monochrome.jpeg` (`logo 2.jpeg`) for the header and footer. A red multiply layer colours the original play triangle and its antialiased edge within an isolated logo group; screen blending on the group removes the black canvas. This preserves the supplied triangle geometry without a white fringe. `dkps-symbol-monochrome.jpeg` (`logo 1.jpeg`) is the favicon. `dkps-wordmark-monochrome.jpeg` (`logo 3.jpeg`) is retained as the text-only reference.
