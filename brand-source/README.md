# DKPS logo source files

The original `Vector.ai`, `Vector.eps`, and `Vector.pdf` files supplied by DKPS are kept here for print and future vector production. The PDF contains light and dark layouts with a coloured symbol; its composition differs from the supplied monochrome JPEG references.

The website uses `public/brand/dkps-logo-monochrome.jpeg` (`logo 2.jpeg`) for the header and footer. `dkps-symbol-monochrome.jpeg` (`logo 1.jpeg`) is the favicon. `dkps-wordmark-monochrome.jpeg` (`logo 3.jpeg`) is retained as the text-only reference. The dark header and footer use screen blending to remove the JPEG's black canvas without changing the supplied artwork.
