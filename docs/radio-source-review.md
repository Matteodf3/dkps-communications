# DKPS radio source review

Source: the 14 supplied `Dukapis Flyer N.pdf` files and `DKPS_Codex_Radio_Source.md` (6 October 2026). The website keeps each DKPS article number and the source product name. Product photographs were extracted from the corresponding flyer. The catalogue shows only specifications that can be stated without reconciling contradictory source values.

## Items for DKPS to confirm

| Article | Source inconsistency or unresolved point |
| --- | --- |
| DKPS-RADHH-018 / DKPS-RADHH-024 | The two articles have different product photographs, but their names, specifications and feature text are otherwise identical in the supplied list. They remain separate catalogue entries. Confirm how the two models differ. |
| DKPS-RADHH-011 | The main feature list includes Galileo in GNSS; the technical table lists GPS, BeiDou and GLONASS only. The website omits the constellation list. |
| DKPS-RADVH-002 | Title and description identify a vehicle/fixed mobile radio, while key features call it a handheld. The technical table says 146 mm and 193 g; key features say 127 mm and 246 g. Vehicle fit and physical specifications need confirmation before configuration. |
| DKPS-RADHH-004 | The technical table's `Bluetooth` field contains dimensions (`40 × 60 × 127 mm`), while its dimensions row says `52 × 55 × 146 mm`. Display, battery, protection, cameras and NFC appear in feature lists without equivalent technical-table confirmation. The website omits those values. |
| DKPS-RADHH-005 / DKPS-RADHH-006 | Their main feature lists include the same 4-inch display, 5,000 mAh battery, IP68, cameras and NFC details as other flyers, but the respective technical tables do not confirm these. The website uses the model-specific network, control, GPS and Wi-Fi details only. |
| DKPS-RADHH-025 | The technical table says `1 GB RAM + 8 GB ROM`; key features say `2 GB RAM + 32 GB storage`. The website omits memory. |
| DKPS-RADHH-015 | The product name says `4 Inch Touchscreen`, while the description and technical table say `1.77-inch LCD`. Main/key features say 3 W speaker; technical table says 2.8 W. The website retains the exact source name, flags the display conflict in the description and omits display and speaker specifications. |
| DKPS-RADHH-017 | The supplied flyer footer differs from the technical table for dimensions, memory and battery. Website values follow the technical table; confirm against the physical product. |
| DKPS-RADHH-003 | The supplied flyer footer differs from the technical table for weight, memory and battery. Website values follow the technical table; confirm against the physical product. |

The supplied stock source lists radios only. The existing body cameras and accessories remain on the website as exploratory options. They are not presented as confirmed stock, and compatibility with the listed radios must be checked before proposing a configuration. In particular, Motorola accessories shown on an operational page should not be assumed to work with a DKPS coded or Hytera radio.
